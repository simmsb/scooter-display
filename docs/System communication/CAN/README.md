The self-contained components of the scooter communicate with each other over can bus.

The known messages are documented in [CAN bus messages](CAN%20bus%20messages.md)

The firmware of components on the bus can be updated, the update process for the display has been documented in [Firmware updates over CAN](Firmware%20updates%20over%20CAN.md)

The following components participate on the CAN Bus:

* Display unit ([Display unit overview](../../Components/Display%20unit/README.md))
* Battery ([Battery Overview](../../Components/Battery/README.md))
* Motor controller ([Motor controller overview](../../Components/Motor%20controller/README.md))
