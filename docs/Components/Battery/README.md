The battery of the Egret GT.

It has a nominal voltage of 48V, and charges at 54V.

It participates on the can bus, and sends these messages: [CAN bus messages > Sent by battery](../../System%20communication/CAN/CAN%20bus%20messages.md#sent-by-battery)

It likely contains a RTC as its charge history messages contain YYMMDDHHMMSS timestamps.
